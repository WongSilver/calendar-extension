# Chrome 应用商店资料（zh-CN）

## 名称

中国节假日日历

## 简短说明

中国节假日日历扩展，支持农历显示、节假日标记、调休安排、月度统计和假期倒计时。

## 详细说明

中国节假日日历是一款简洁的浏览器日历扩展，打开工具栏弹窗即可快速查看公历、农历和中国法定节假日安排。

主要功能：

- 显示公历日期、农历、干支、生肖、节气和数九信息。
- 标记中国法定节假日与调休工作日。
- 统计当月工作日、休息日、法定假期和调休天数。
- 显示下一个节假日、剩余天数和放假日期范围。
- 支持年份、月份、按钮和鼠标滚轮导航。
- 支持周日或周一作为一周起始日。
- 提供小、中、大三档日期字号。
- 支持亮色、暗色和跟随系统主题。
- 节假日数据按需更新并缓存在本地，网络不可用时仍可使用基础日历和已有缓存。

本扩展不收集个人信息或浏览历史。用户设置和节假日数据仅保存在浏览器本地。

## 类别

生产力工具

## 单一用途说明

本扩展的单一用途是提供中国公历、农历、法定节假日、调休安排和假期倒计时查询。

## 权限用途说明

### storage

用于在浏览器本地保存日历显示设置、节假日缓存和缓存更新时间，减少重复请求并保留用户偏好。数据不会上传给开发者。

### 主机权限 `https://www.shuyz.com/*`

仅用于从公开数据源获取中国法定节假日与调休数据。请求不包含用户个人信息、浏览历史或网页内容。

## 远程代码

本扩展不使用远程代码。所有 JavaScript 和 CSS 均包含在扩展程序包中；网络请求仅获取结构化节假日数据。

## 数据使用声明

- 不收集或出售用户数据。
- 不将用户数据用于广告、信用评估或与扩展单一用途无关的目的。
- 不传输个人身份信息、健康信息、财务信息、身份验证信息、位置、浏览历史或用户活动。
