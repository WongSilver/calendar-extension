# 🗓️ 中国节假日日历

一个现代化的中国节假日日历 Edge 浏览器扩展，支持农历显示、节假日标记、滚轮切换月份/周。

## ✨ 功能特点

### 核心功能
- **📅 农历显示** - 显示农历日期、节气、传统节日、干支年月日、生肖、数九信息
- **🎉 节假日标记** - 法定节假日红色标记，调休日橙色标记，带礼物/公文包图标
- **🖱️ 滚轮切换** - 使用鼠标滚轮快速切换月份或周（可设置）
- **📊 月度假期列表** - 侧边栏显示当月所有假期安排，支持滚动

### 设置选项
- **🔄 数据刷新** - 手动刷新节假日数据（10分钟冷却）
- **📅 每周起始日** - 可选周日或周一开始
- **🎨 主题切换** - 支持亮色/暗色/跟随系统
- **💬 日期气泡** - 可开关鼠标悬停日期气泡提示
- **📜 滚动模式** - 可选切换月份或周

## 🛠️ 技术栈

- **⚡ Next.js 16** - React 框架，使用 App Router
- **📘 TypeScript 5** - 类型安全的 JavaScript
- **🎨 Tailwind CSS 4** - 实用优先的 CSS 框架
- **🧩 shadcn/ui** - 高质量 UI 组件库
- **📆 lunar-typescript** - 中国农历转换库
- **📅 date-fns** - 现代日期处理库

## 📦 安装使用

### 开发模式

```bash
# 安装依赖
bun install

# 启动开发服务器
bun run dev

# 代码检查
bun run lint
```

### 打包扩展

```bash
# 构建并打包 Edge 扩展
bun run build:extension
```

### 安装扩展

1. 打开 Edge 浏览器，访问 `edge://extensions/`
2. 开启「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择项目中的 `extension` 目录

## 🎨 界面预览

扩展打开后显示：
- **左侧**：月历视图，显示公历、农历、节假日标记
- **右上**：选中日期的详细信息（农历、干支、生肖等）
- **右下**：本月假期列表，支持滚动查看

|------|------|

## ⚙️ 设置面板

点击右上角齿轮图标打开设置：

| 设置项 | 说明 |
|--------|------|
| 节假日数据 | 显示更新时间，点击刷新按钮更新数据（10分钟冷却） |
| 每周起始日 | 选择周日或周一开始 |
| 主题 | 明亮/暗色/跟随系统 |
| 日期气泡 | 显示/隐藏鼠标悬停日期气泡 |
| 滚动切换 | 月（按月切换）/ 周（按周切换） |

## 📝 数据来源

节假日数据来自：[中国节假日 API](https://www.shuyz.com/githubfiles/china-holiday-calender/master/holidayAPI.json)

- **缓存策略**：永久缓存，直到手动刷新或缓存不存在时才请求
- **刷新限制**：10分钟内只能刷新一次
