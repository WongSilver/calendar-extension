# 中国节假日日历 Edge 扩展

一个功能丰富的中国节假日日历 Edge 浏览器扩展，支持农历显示、节假日标记、月度统计和假期倒计时。

## 功能特性

### 📅 日历功能
- **农历显示** - 完整显示农历日期、干支纪年、生肖、节气
- **节假日标记** - 红色背景标记假期，橙色背景标记调休工作日
- **假/班标记** - 右上角显示"假"或"班"标识
- **周末高亮** - 周末日期红色显示

### 📊 统计信息
- **月度统计** - 工作日、休息日、假期、调休天数统计
- **假期倒计时** - 显示下一个假期的剩余天数和日期范围

### ⚙️ 个性化设置
- **字号调节** - 小/中/大三档字号可选
- **主题切换** - 支持亮色/暗色/跟随系统
- **周起始日** - 周日或周一开始
- **滚动模式** - 按月或按周滚动切换
- **日期气泡** - 悬停显示详细信息

### 🎨 界面特点
- **响应式设计** - 适配不同屏幕尺寸
- **深色模式** - 完美支持暗色主题

## 技术栈

- **Next.js 16** - React 框架
- **TypeScript** - 类型安全
- **Tailwind CSS** - 样式框架
- **shadcn/ui** - UI 组件库
- **lunar-typescript** - 农历计算库
- **date-fns** - 日期处理

## 安装使用

### 开发模式

```bash
# 安装依赖
bun install

# 启动开发服务器
bun run dev

# 构建生产版本
bun run build
```

### 安装扩展

1. 运行 `bun run build` 构建项目
2. 打开 Edge 浏览器，访问 `edge://extensions/`
3. 开启"开发人员模式"
4. 点击"加载解压缩的扩展"
5. 选择 `.output/chrome-extension` 目录

## 项目结构

```
src/
├── app/                    # Next.js 页面
├── components/
│   ├── ChineseCalendar.tsx # 主日历组件
│   ├── CalendarDayCell.tsx # 日期格子组件
│   ├── CalendarSidebar.tsx # 侧边栏组件
│   └── ui/                 # UI 组件库
├── lib/
│   ├── calendar.ts         # 日历工具函数
│   └── holidays.ts         # 节假日数据处理
└── hooks/                  # 自定义 Hooks
```
